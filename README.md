# Business Management SaaS

A multi-tenant Business Management System designed for small and medium-sized businesses in Japan.

日本の中小企業・店舗向けのビジネス管理システムです。

## Project Overview

A centralized platform for managing business operations, customers, staff, services, appointments, payments and business performance.

This is a personal portfolio development project.

## Technology Stack

- PHP 8.5
- Laravel 13
- MySQL 8.4
- Redis
- Docker
- Laravel Sail
- JavaScript
- Git and GitHub

## Planned Features

- User authentication and authorization
- Business registration and multi-tenancy
- Business profiles and settings
- Customer management (CRM)
- Staff management
- Service and product management
- Appointment and reservation management
- Calendar and scheduling
- Payment and invoice management
- Sales reports and analytics
- CSV import and export
- REST API with Laravel Sanctum
- Email notifications and background jobs
- Activity logs and security controls
- AI-powered business insights
- Japanese and English language support

Note: These features are part of the development roadmap and are not all implemented yet.

## Local Installation

1. Clone the repository
2. Install Composer dependencies
3. Configure the `.env` file
4. Start Docker containers
5. Generate the application key
6. Run database migrations
